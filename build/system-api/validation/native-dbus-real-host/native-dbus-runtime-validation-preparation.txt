Native D-Bus Runtime Preparation Checklist
OS family: Linux

1. install-native-dbus-extension - Instalar y habilitar la extension PECL `dbus` para que PHP pueda pedir el bus name y exportar el objeto D-Bus.
   - sudo apt-get update
   - sudo apt-get install -y php-pear php-dev libdbus-1-dev pkg-config
   - sudo pecl install dbus
   - php --ri dbus
2. install-dbus-daemon - Asegurar que `dbus-daemon` este instalado y disponible en el host.
   - sudo apt-get update
   - sudo apt-get install -y dbus
   - dbus-daemon --version
3. materialize-system-bus-socket - Confirmar que el socket del system bus exista y que el servicio D-Bus del sistema este activo.
   - sudo systemctl status dbus
   - test -S /run/dbus/system_bus_socket && echo system-bus-socket-ready
4. install-dbus-client-tooling - Instalar al menos una herramienta de cliente D-Bus (`busctl` o `gdbus`) para contrastar el runtime desde el host.
   - sudo apt-get update
   - sudo apt-get install -y systemd dbus
   - busctl --version || gdbus --version
5. retry-native-bus-ownership - Reintentar el ownership real del bus solo cuando el host confirme extension PECL dbus, daemon, socket y tooling del sistema disponibles.
   - php scripts/run_native_dbus_real_host_validation.php --format text
