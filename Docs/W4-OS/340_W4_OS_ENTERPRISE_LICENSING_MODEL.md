# 340 · W4 OS — Enterprise Licensing Model

> **Edición documental:** 0.1 · **Fecha:** 2026-09-08 · **Idioma:** español  
> **Área:** Modelo comercial · **Responsabilidad propuesta:** Producto y operación comercial  
> **Estado:** especificación de diseño; implementación y calificación no acreditadas por esta entrega.

## Propósito, contexto y objetivos

Separar derechos de uso de componentes libres de contratos empresariales de servicio.

## Alcance, arquitectura y decisiones

Contrato propuesto define dispositivos/usuarios cubiertos, soporte, gestión, acceso a servicios y salida. Licencias upstream conservan sus términos; no se relicencia toda la distribución.

## Componentes y flujo operativo

1. Identificar componentes y servicio
2. revisar obligaciones
3. definir métrica de contratación
4. acordar
5. operar
6. finalizar con exportación.

## Seguridad y riesgos

No imponer restricciones contractuales que contradigan derechos de software libre aplicables. Validar jurisdicción y términos con asesoría especializada.

## Criterios de aceptación

Aceptar contrato trazable a funciones reales y procedimiento de salida sin bloqueo de datos.

## Rendimiento y evidencia

Medir disputas de alcance.
