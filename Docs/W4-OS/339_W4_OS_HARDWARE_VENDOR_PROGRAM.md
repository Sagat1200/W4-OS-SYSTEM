# 339 · W4 OS — Hardware Vendor Program

> **Edición documental:** 0.1 · **Fecha:** 2026-09-08 · **Idioma:** español  
> **Área:** Modelo comercial · **Responsabilidad propuesta:** Producto y operación comercial  
> **Estado:** especificación de diseño; implementación y calificación no acreditadas por esta entrega.

## Propósito, contexto y objetivos

Crear programa de hardware con requisitos de soporte verificables.

## Alcance, arquitectura y decisiones

Proveedor aporta modelos/revisiones, firmware redistribuible cuando aplique, unidades de prueba y escalamiento técnico. W4 publica alcance de compatibilidad, no aval genérico.

## Componentes y flujo operativo

1. Recibir propuesta
2. revisar componentes
3. ejecutar matriz
4. acordar mantenimiento
5. publicar nivel
6. reevaluar cambios.

## Seguridad y riesgos

No aceptar sustitución de componentes en producción sin repetir pruebas afectadas. Revisar controladores sin fuente y fin de soporte.

## Criterios de aceptación

Aceptar modelo con expediente y respuesta acordada a regresiones.

## Rendimiento y evidencia

Medir tiempo de resolución y revisiones no notificadas.
