# 408 · W4 OS — V1 Home Scope

> **Edición documental:** 0.1 · **Fecha:** 2026-09-08 · **Idioma:** español

## Propósito, contexto y objetivos

Cerrar V1 Home con tareas domésticas y privacidad comprobadas.

## Alcance, arquitectura y decisiones

Perfil de apps pequeñas, onboarding accesible, cuenta local, conectividad, actualizaciones visibles, respaldo externo y recuperación guiada. Gaming opcional según hardware calificado.

## Componentes y flujo operativo

1. Instalar
2. configurar
3. trabajar con documentos/medios
4. bloquear/suspender
5. actualizar
6. recuperar archivo y sistema.

## Seguridad y riesgos

No requerir cuenta W4 ni consentimiento de telemetría para funciones base. No incluir controladores no calificados por marketing.

## Criterios de aceptación

Aceptar recorrido doméstico sin dependencia cloud y tareas de accesibilidad completadas.

## Rendimiento y evidencia

Medir éxito de usuario y memoria ociosa.
