# 357 · W4 OS — ISO 27001 Alignment

> **Área:** Alineación de controles · **Responsabilidad propuesta:** Seguridad y cumplimiento  
> **Estado:** especificación de diseño; implementación y calificación no acreditadas por esta entrega.

## Propósito, contexto y objetivos

Aportar evidencia técnica a un SGSI alineado con ISO/IEC 27001.

## Alcance, arquitectura y decisiones

W4 puede apoyar inventario, accesos, cambios, logs y recuperación; la norma aborda un sistema de gestión organizacional. Esta documentación no declara certificación del producto ni de W4.

## Componentes y flujo operativo

1. Definir alcance SGSI
2. identificar controles pertinentes
3. mapear capacidades
4. recopilar evidencia
5. evaluar brechas
6. planificar tratamiento.

## Seguridad y riesgos

No copiar texto normativo extenso ni inventar aprobación de auditor. Evidencia de dispositivo contiene datos que requieren acceso controlado.

## Criterios de aceptación

Aceptar matriz revisada con responsables organizacionales y límites claros.

## Rendimiento y evidencia

Medir evidencias faltantes y antigüedad.

## Referencias técnicas contrastadas

Consulta: 2026-09-08. Las fuentes describen mecanismos externos; los requisitos y elecciones W4 son propuestas de esta colección.
